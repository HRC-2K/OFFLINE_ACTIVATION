HRC Offline Utility Tool

Standalone Windows GUI manager for game scripts, utility launchers, and offline isolation.

Download v2.0 Release View on GitHub

⚡ Quick Start Guide

  1. Download HRC_Offline_Utility_Tool_v2.0.zip from GitHub releases.
  2. Extract the archive and launch OAT.exe.
  3. Select your preferred download/portable directory using Browse...
  4. Choose any script or launcher and click Run Selected.

✨ Key Features in v2.0

  • Hybrid Script Execution: Runs local .ps1 scripts offline or streams the latest version directly from GitHub when connected.
  • Persistent Configurations: Automatically stores download paths inside config.json.
  • Smart Registry Detection: Detects installed launchers across standard paths and custom drives (C: through Z:).
  • Dark Gamer UI: Styled layout designed with Segoe typography, expanded list boxes, and real-time logging.
