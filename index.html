⚡ Quick Start

Option A: GUI Manager Executable (Recommended)

  1. Click Download v2.0 Release above to get HRC.Offline.Activation.Tool.zip.
  2. Extract the archive and run OAT.exe.
  3. Select your preferred directory using Browse... (saved automatically).
  4. Choose any tool or script and click Run Selected or Download.

Option B: Pure PowerShell Version

Run the master menu directly from PowerShell (No installation needed):

irm "https://raw.githubusercontent.com/HRC-2K/OFFLINE_ACTIVATION/main/menu_ps.ps1" | iex

📌 Note: Administrator privileges are required to manage firewall rules, network adapters, and silent installers.

✨ Key Features & Modules

🎮 Offline Gaming Tools

  • Multi-Launcher Isolator: Scans drives C:–Z: and blocks network access for Steam, Ubisoft, Epic, and Rockstar while keeping your PC online.
  • EA Adapter Offline Tool: Temporarily toggles network adapters for genuine offline launch in the EA App.
  • Custom Directory Blocker: Creates firewall rules for all .exe files inside any chosen folder.
  • One-Click Unblocker: Instantly restores full network access for all blocked launchers.

🛠️ Silent Installer & Upgrader

  • Chris Titus Tech Utility: One-click launch for Windows tweaks.
  • Gaming Launchers: Steam, Ubisoft Connect, Epic Games, Rockstar, EA App.
  • Core Utilities: UltraViewer, Cloudflare WARP 1.1.1.1, FAB (Firewall App Blocker), TcNo Account Switcher, Bulk Crap Uninstaller.
  • Batch Downloader: Download multiple applications simultaneously.

🔒 Philosophy: Digital Ownership & Control

Modern launchers often demand persistent internet connections, background updates, and telemetry collection even for offline single-player games. This project aims to:

  • 🎮 Simplify launching games completely offline.
  • 🔒 Eliminate background telemetry and launcher updates.
  • ⚡ Automate complex Windows Firewall & network adapter workflows.
  • 📦 Keep software lightweight, transparent, and user-controlled.
